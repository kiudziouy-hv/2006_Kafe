# Demo

Thư mục dành cho tài liệu chuẩn bị buổi báo cáo:

- `kich-ban-demo.md`: kịch bản từng bước (người nói, thao tác, dữ liệu nhập, kết quả mong đợi).
- `du-lieu-mau.md`: tài khoản, bàn, món, số tiền dùng khi demo.
- `hoi-dap.md`: câu hỏi dự kiến và câu trả lời.

Các tệp trên chưa được viết; xem docs/requirements/README.md để biết chức năng nào đã chạy thật.
