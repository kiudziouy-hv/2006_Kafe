# VTPH-Coffee
Coffee Shop Management System

## Thư mục

- [`frontend/`](frontend/) — giao diện web 2006 Kafé (React + Vite + Tailwind), dựng theo Figma. Bản hiện tại **chỉ có giao diện và dữ liệu giả, chưa nối backend**. Xem hướng dẫn chạy và lưu ý trong [frontend/README.md](frontend/README.md).
- [`backend/`](backend/) — API backend (Java 21, Spring Boot, MySQL). Mới có khung dự án, đăng nhập/phân quyền theo vai trò và API sơ đồ bàn. Xem [backend/README.md](backend/README.md).
- [`database/`](database/) — script CSDL MySQL 8.4 (lược đồ, trigger, dữ liệu mẫu, view/procedure). Xem [database/README.md](database/README.md).
